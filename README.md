# CyberX Lucky Drop 3.0 — тестовый серверный прототип

Включено: Telegram WebApp initData-проверка подписи (при выключенном TEST_MODE), раздельные Cyber Coin и призы, уникальные одноразовые билеты, серверная прокрутка за 50 CC, отдельные выигрыши, роли owner/staff/player, административное подтверждение, журнал операций, настройка вероятностей, SQLite и мобильный интерфейс с горизонтальной лентой.

**ЭТО НЕ PRODUCTION-РЕЛИЗ.** Пока нет интеграции с LANGAME, настоящих QR-кодов/сканера, подтверждения фактического начисления до смены статуса, защиты от всех эксплуатационных рисков, резервного копирования, мониторинга и полноценного тестирования. Интерфейс выдаёт коды в виде текста, готового для дальнейшей печати/QR-генерации. Не используйте с реальными бонусами.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
export CYBERX_TEST_MODE=1
export OWNER_TELEGRAM_ID=933124893
uvicorn server:app --host 127.0.0.1 --port 8000
```

Открыть http://localhost:8000 — локальный тестовый вход работает под владельцем (только при CYBERX_TEST_MODE=1). Для проверки посетителя можно обращаться к API с `init_data: "dev:123456"` в тестовом режиме.

## Для размещения в Telegram

1. Нужен HTTPS-сервер с Python, а не один GitHub Pages (он обслуживает только статические файлы). Хранение базы данных должно быть постоянным и с резервными копиями.
2. В настройках сервера (не в HTML и не в публичном GitHub!) задать `BOT_TOKEN`, `OWNER_TELEGRAM_ID=933124893`, `CYBERX_TEST_MODE=0`.
3. Создать нового пользователя/хранилище БД, обеспечить HTTPS и ограничить доступ. Настроить домен через BotFather на URL нового сервера **только после тестирования**.
4. Для выдачи действительных призов нужно доработать подтверждение реального начисления в LANGAME и обработку ошибок. Сейчас отметка `delivered` лишь меняет статус в нашей базе.

**Безопасность:** токен никогда не публиковать в GitHub/чате. `dev:`-авторизация допустима только при локальной разработке: если её оставить на публичном сервере, любой сможет притвориться владельцем. Физический билет выдаётся за выигрыш на колесе фортуны. В приложении Cyber Coin используются только для прокруток; выигрыши 25–10000 игровых бонусов не конвертируются обратно в CC. По правилам клуба бонусами можно покрывать до 25% стоимости сессии LANGAME.
